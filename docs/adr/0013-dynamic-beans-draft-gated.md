# Dynamic beans: draft-gated

A member invocation may create new beans mid-work — a discovered bug, a split-off sub-task, a cross-role handoff. These **dynamic beans** land in `draft` status, not `todo`. Because `beans list --ready` excludes `draft`, the dispatch-time filter is **hard** (beans enforces it; hordr adds zero governance code). The human reviews the drafts surfaced by `hordr fleet status` and flips approved beans to `todo` via `beans update <id> -s todo` to enable dispatch.

The creation-time half is **soft**: the member's persona instructs it to create with `beans create ... -s draft`. If a member defies the persona and creates with `-s todo`, the bean auto-dispatches — recoverable via the ADR-0010 failure model (crash → `blocked`; or it completes fine) and detectable via the invocation audit as a provenance outlier. This split is deliberate: dispatch-time gating is the load-bearing guarantee and costs nothing (beans already does it); creation-time gating is a convention that can be hardened later (`hordr bean create` wrapper forcing `-s draft`) only if the soft half proves unreliable in practice.

Rationale: every other fleet decision treats beans as the universal control surface and the daemon as a dumb dispatcher. Adding a hordr-side governance layer for dynamic beans specifically would be the one place the daemon "gets smart" — and about the wrong thing (second-guessing bean state the human can edit directly). Serialized dispatch (ADR-0009) provides a natural review window between tasks anyway; the human has a beat to flip a too-eager bean to `draft` before it is dispatched. Runaway cycles (member A creates for member B, B for A, indefinitely) are self-revealing via `fleet status` task-count and recoverable via `fleet abort` or marking beans `draft` — the daemon does not predict or prevent, it surfaces.

A dynamic bean file rides in the **creating task's commit** (an artifact of that work — "while doing X, I discovered Y"). The bean later gets its own commit when dispatched and worked. Two commits per dynamic bean, clean git provenance.
