hordr

A herdr plugin that gives coding agents isolated git worktrees and panes, with beans as their briefs.

Quick start Read the docs 
$ hordr run hordr-0001
# → started hordr-0001 in hordr-0001 (role: implementer, pane: wX:pNEW)

# one bean, one worktree, one agent — fire and forget.

Single-bean

One bean, one isolated worktree, one agent. Fire-and-forget — the agent commits, you review.

Fleet

A team of agents on a milestone in parallel. Each epic gets its own worktree; hordr fleet check advances them.

Beans

Work contracts as briefs: milestone → epic → task. The engine dispatches the unblocked, rolls up status, merges.
