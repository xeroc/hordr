Hordr is a [herdr](https://github.com/ogulcancelik/herdr) plugin. It wires three
things together so an agent can pick up a unit of work, do it in isolation, and
hand back a clean commit:

- **herdr** — panes and linked git worktrees.
- **a harness** — the agent itself (opencode, claude code, …).
- **beans** — the work contract: `milestone → epic → task`.

The engine owns dispatch, rollup, and merge. Agents just work the bean in front
of them.
